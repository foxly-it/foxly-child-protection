2. Hosting über GitHub Pages

Diese statische Website und die Filterliste werden über GitHub Pages bereitgestellt. Anbieter ist GitHub, Inc., 88 Colin P Kelly Jr Street, San Francisco, CA 94107, USA. Beim Abruf verarbeitet GitHub technisch erforderliche Verbindungsdaten. GitHub weist insbesondere darauf hin, dass die IP-Adresse zu Sicherheitszwecken protokolliert und gespeichert wird.

Das gilt auch für den automatischen Abruf der Filterliste durch AdGuard Home: Dabei werden die IP-Adresse und die Software-Kennung (User-Agent) des abrufenden Servers übermittelt. Wir selbst erhalten keine Zugriffsprotokolle und können Abrufe keinen Personen zuordnen.

3. Keine Cookies, keine Analyse, keine eingebetteten Inhalte

Wir setzen keine Cookies ein und verwenden keine Webanalyse, kein Werbetracking, keine Social-Media-Pixel und keine extern geladenen Schriftarten oder Grafiken. Ein kleines, lokal ausgeführtes Skript zeigt das Alter der Liste an und kopiert auf Klick Text in die Zwischenablage. Es überträgt keine Daten. Verbindungen zu GitHub, den Quelllisten oder rootguard.foxly.de entstehen erst, wenn du einen entsprechenden Link öffnest.
