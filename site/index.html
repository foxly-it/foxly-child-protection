In AdGuard Home einbinden

  1. Filter → DNS-Sperrlisten → Sperrliste hinzufügen → Eigene Liste hinzufügen, Name $title, obige URL eintragen.
  2. Einstellungen → Client-Einstellungen: jedes Kindergerät als persistenten Client anlegen (IP, MAC oder ClientID) und das Tag $client_tag setzen.
  3. Prüfen unter Filter → Benutzerdefinierte Filterregeln → Filterung überprüfen: Domain aus der Liste und als Client die IP des Kindergeräts eingeben. Für andere Clients darf sie nicht blockiert sein.

DNS-Filterung ist ein Baustein, kein vollständiger Jugendschutz. Sie lässt sich z. B. über VPNs, verschlüsseltes DNS (DoH/DoT) oder mobile Daten umgehen und filtert keine Inhalte innerhalb erlaubter Seiten.
