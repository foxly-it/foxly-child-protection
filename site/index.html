AGH=http://adguard.lan   # Adresse deiner Instanz

# Kindergerät: blockiert (||1337x.to^$$ctag=…)
curl -su admin -G "$$AGH/control/filtering/check_host" \
  -d name=1337x.to -d client=IP-KINDERGERÄT

# Erwachsenengerät: nicht blockiert

Funktionsweise

Automatisch.
Und konservativ.

GitHub Actions erzeugt die Liste jeden Morgen neu. Veröffentlicht wird nur, was alle Prüfungen bestanden hat. Schlägt etwas fehl, bleibt die letzte funktionierende Version online.

01 · TÄGLICH

Aktualisierung um 04:00

Quellen abrufen, Formate erkennen (AdGuard-Regeln, Domainlisten, Hosts-Dateien), Duplikate und redundante Subdomains entfernen.

02 · GEZIELT

Nur für Kindergeräte

Jede Regel lautet ||domain^$$ctag=$client_tag. Sie sperrt die Domain samt Subdomains, aber keine Namen, die nur ähnlich klingen.

03 · GEPRÜFT

Mit der AdGuard-Engine

Vor jeder Veröffentlichung prüft die Filter-Engine von AdGuard Home jede Regel, ob sie greift und Clients ohne Tag nie trifft.

04 · SICHER

Nichts wird umgedeutet

Ausnahmen, Umleitungen und unklare Regeln aus externen Quellen werden verworfen. Eine manipulierte Quelle kann nichts freigeben.

05 · ANPASSBAR

Allowlist und Blocklist

Eigene Domains sperren oder freigeben. Die Allowlist hat immer Vorrang, Änderungen sind wenige Minuten später online.

06 · TRANSPARENT

Nachvollziehbar

Jede inhaltliche Änderung landet in der Git-Historie, mit SHA-256 jeder Quelle und vollständigem Prüfprotokoll.

Kein vollständiger Jugendschutz. DNS-Filterung lässt sich über VPNs, verschlüsseltes DNS (DoH/DoT) oder mobile Daten umgehen und sieht keine Inhalte innerhalb erlaubter Seiten. Sie ergänzt Gerätebeschränkungen und Begleitung, ersetzt sie aber nicht.
